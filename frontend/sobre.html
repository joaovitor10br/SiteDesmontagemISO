Sobre o projeto

Este projeto foi desenvolvido com o objetivo de automatizar a criação de imagens ISO Linux personalizadas.

A aplicação permite extrair uma ISO original, modificar o sistema interno via chroot, adicionar pacotes (.deb para Debian/Ubuntu, ou pacotes Arch via pacman) e reconstruir a imagem final pronta para inicialização em BIOS e UEFI, preservando a estrutura de boot original.
